# AetherDrive Automotive Group

Welcome to the AetherDrive Automotive Group website! This project showcases our commitment to providing premium automotive solutions with a futuristic aesthetic. Below is an overview of the website's features, structure, and setup instructions.

## Project Overview

AetherDrive Automotive Group specializes in electric vehicles and innovative automotive solutions. Our website is designed to reflect our brand's premium quality and forward-thinking approach. 

### Features

- **Hero Section**: A modern hero section with a bold headline and animated call-to-action button to engage visitors immediately.
- **Featured Electric Vehicles**: A dedicated section highlighting our latest electric vehicle offerings.
- **Customer Testimonials**: Real feedback from our satisfied customers to build trust and credibility.
- **Financing Options**: Information on financing solutions available for our customers.
- **Responsive Design**: The website is fully responsive, ensuring a seamless experience across all devices.
- **Dark Theme with Neon Accents**: A visually striking design that enhances user engagement and aligns with our brand identity.
- **Smooth Animations**: Enhanced user experience through smooth transitions and animated elements.

## Installation

To get started with the AetherDrive Automotive Group website, follow these steps:

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/aetherdrive-automotive.git
   ```

2. Navigate to the project directory:
   ```
   cd aetherdrive-automotive
   ```

3. Install the necessary dependencies:
   ```
   npm install
   ```

4. Open `src/index.html` in your web browser to view the website.
